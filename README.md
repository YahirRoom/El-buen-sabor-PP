#  El Buen Sabor

##  Descripción

**El Buen Sabor** es una página web interactiva y responsiva para una cafetería y lonchería, desarrollada con HTML, CSS y JavaScript.

El proyecto permite explorar un catálogo de productos, filtrarlos por categorías, realizar búsquedas y gestionar un carrito de compras de manera dinámica.

Además, cuenta con un **diseño responsivo (Responsive Web Design)** que adapta la interfaz a diferentes tamaños de pantalla, ofreciendo una experiencia de navegación cómoda en computadoras, tabletas y dispositivos móviles.

##  Funcionalidades

- Visualización de productos cargados desde un archivo JSON.
- Filtrado de productos por categorías:
  - Comida / Lonchería
  - Cafetería y bebidas
  - Tienda y snacks
- Buscador de productos en tiempo real.
- Carrito de compras interactivo.
- Contador de productos agregados al carrito.
- Incremento y disminución de cantidades.
- Eliminación de productos del carrito.
- Cálculo automático del total de compra.
- Diseño responsivo adaptable a computadoras, tabletas y dispositivos móviles.
- Animaciones y transiciones visuales.

##  Tecnologías utilizadas

- **HTML5:** estructura y contenido de la página.
- **CSS3:** diseño responsivo, Flexbox, Media Queries, estilos y animaciones.
- **JavaScript:** interactividad y manipulación del DOM.
- **JSON:** almacenamiento de la información del catálogo.
- **Git y GitHub:** control de versiones.

## Cómo ejecutar el proyecto

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/YahirRoom/El-buen-sabor-PP
   ```

2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Ejecutar `index.html` mediante Live Server.
4. Explorar el catálogo y utilizar las funcionalidades disponibles.

**Nota:** Se recomienda utilizar un servidor local debido a que los productos se cargan mediante `fetch()` desde un archivo JSON.
